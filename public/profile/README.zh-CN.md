## 我怎么工作 &nbsp;<sub><code>git log --graph</code></sub>

**`01` 设定框架。** 我写下问题、边界，以及什么才算完成：哪些测试、哪个重播、哪个哈希。

**`02` 运行。** Claude Code 与 Codex（含 Codex Cloud）在我审阅的分支上写大部分的程序、测试与文档。这些仓库里大多数的行是 agent 打出来的；每一个主张都由我负责。

**`03` 决定。** 由证据决定，不由信心决定：测试、独立的重播检查器、内容哈希。负面结果和正面结果一样，用同样的标准留下来。
